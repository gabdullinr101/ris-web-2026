Тема: Разработка веб-сервиса управления бронированием тренировок и занятостью тренеров
Статус темы: на проверке (заявка в docs/project-proposal.md)
Стек: Vue 3 + ASP.NET Core + PostgreSQL (клиент — в папке frontend, сервер и база позже)


## Запуск клиента (ЛР3)

Нужен Node.js LTS (22.18 или новее). Проверка: `node -v` и `npm -v`.

```bash
cd frontend
npm install
npm run dev
```

Открыть адрес Vite, обычно `http://localhost:5173`.

Экраны (переключаются кнопками в шапке): «Список» — записи на тренировки, «Создать» — форма новой записи, «Вход» — логин и пароль. Сервер и база для запуска не нужны, кнопки форм пока ничего не сохраняют.
