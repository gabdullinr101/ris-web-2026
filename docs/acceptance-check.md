# Проверка трёх критериев на стенде

Критерии приёмки из ЛР1 (docs/lab-01-requirements.md). Проверка - на живом стенде: Vue `:5173` → API `:5000` → PostgreSQL. Mock выключен (`VITE_USE_MOCK=false`). Один и тот же `id` прослеживается на экране, во вкладке Network (F12 → Сеть / Network → Fetch/XHR) и в таблице `bookings`.

Перед проверкой: сервер и клиент запущены по README, база создана `dotnet ef database update`.

## Критерий 1. Создать запись

| | |
|---|---|
| Дано | администратор вошёл (`admin`) |
| Когда | «Создать» → вид тренировки 5-80 символов, зал числом (1-3), описание 10-500 символов → «Создать» |
| Тогда | запись со статусом «Новая» (`New`) и номером `БР-…` |

| Шаг | Ожидание | Где смотреть |
|-----|----------|--------------|
| нажать «Создать» | переход на список, новая строка, статус «Новая» | экран: колонки `id`, «Номер», «Статус» |
| запрос | `POST /api/bookings` → `201`, в ответе `id`, `number`, `"status":"New"`, `"assigneeUserId":null` | Network → строка `bookings` → Response |
| база | строка с тем же `id`, `status = 'New'`, `assignee_user_id` пустой | `SELECT id, number, title, status, assignee_user_id FROM bookings WHERE id = <id>;` |
| отказ | вид тренировки `Сил` → ошибка под полем, строка не появилась | экран; Network: запроса нет, форма остановила сама |

## Критерий 2. Назначить тренера

| | |
|---|---|
| Дано | администратор вошёл, есть запись в статусе `New` |
| Когда | в строке записи выбирает тренера → «Назначить» (отдельное действие, статус не трогает) |
| Тогда | у записи есть тренер, статус остался `New` |

| Шаг | Ожидание | Где смотреть |
|-----|----------|--------------|
| «Назначить» | сообщение «Запись БР-…: назначен тренер …», в колонке «Тренер» имя, статус «Новая» | экран |
| запрос | `PATCH /api/bookings/<id>/assignee` с телом `{"assigneeUserId":2}` → `200`, `"status":"New"` | Network |
| база | `assignee_user_id = 2`, `status = 'New'` | тот же `SELECT` |
| отказ | тренер пробует назначить → `403` | коллекция, запрос 11 |

## Критерий 3. Тренер перевёл в работу

| | |
|---|---|
| Дано | назначенный тренер вошёл (`trainer`) |
| Когда | в своей записи нажимает «Подтвердить» (`New → InProgress`) |
| Тогда | статус «Подтверждена тренером»; другой тренер ту же запись не двигает |

| Шаг | Ожидание | Где смотреть |
|-----|----------|--------------|
| вход `trainer` | в списке только его записи | экран |
| «Подтвердить» | статус «Подтверждена тренером», кнопки сменились на «Провести» / «Отменить» | экран |
| запрос | `PATCH /api/bookings/<id>/status` с телом `{"status":"InProgress"}` → `200` | Network |
| база | `status = 'InProgress'` | тот же `SELECT` |
| отказ | `trainer2` меняет статус этой записи → `403` «Менять статус может только тренер, назначенный на эту запись»; в его списке записи нет | коллекция, запрос 16; экран под `trainer2` |

## Сохранность

Остановить API (`Ctrl+C`), снова `dotnet run`, обновить список: запись с тем же `id`, тренером и статусом на месте.
