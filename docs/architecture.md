# Архитектура

```
Vue 3 + Vite             ASP.NET Core              PostgreSQL
localhost:5173  ───────► localhost:5000  ───────► localhost:5432
                  HTTP                    запросы к БД
```

Пример запроса от Vue к серверу:

```
POST http://localhost:5000/api/bookings
Content-Type: application/json

{ "title": "Персональная тренировка, силовая", "hallId": 2, "description": "Клиент новичок, нужна программа на 4 недели" }

→ 201 Created
{ "id": 17, "number": "БР-0017", "status": "New" }
```

Подпись: архитектура web-ИС семестра

- Vue (порт 5173) рисует экраны и отправляет HTTP-запросы.
- ASP.NET Core (порт 5000) проверяет роли и правила и отвечает клиенту.
- PostgreSQL (порт 5432) хранит данные.
- Прямой стрелки от браузера к базе нет: иначе клиент обошёл бы серверные правила (например, тренер смог бы изменить чужую запись).
